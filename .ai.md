## Non-Negotiable Invariants

1. **Continuous Doc API Updates**: The [`.ai/doc-api.md`](file:///c:/Users/ANIK/Desktop/Gemejime/Document%20AI%20Parsers/.ai/doc-api.md) file MUST be kept updated on **every code change or addition**, regardless of how small the modification is.
2. **Secured Logging**: All logging must be structured JSON. Strictly redact PII, document text spans, customer secrets, authorization tokens, and presigned URLs before emission.
3. **GIL Isolation**: Blocking model inference loops (Docling, PyTorch, Whisper, PaddleOCR) MUST run inside worker threads via `asyncio.to_thread()`, keeping Temporal heartbeat emissions reliable every 10 seconds.
4. **Normalized Coordinates**: All document bounding box coordinates MUST be normalized to unit float bounds $[0.0, 1.0]$.
5. **Direct S3 Parquet Egress**: Tabular datasets must be written directly to S3 as Parquet files under deterministic content-addressed keys.
6. **Code Cleanliness**: All code must pass `ruff check`, `ruff format --check`, and strict `mypy` typechecks.

## Git Commit Standards

- **Git Commit Frequency**: Commit code as you build. Every working session or phase must contain **at least two git commits**.
- **Conventional Commit Patterns**: All git commit messages must strictly adhere to the following prefixes:
  - `feat:` for new features 
  - `fix:` for bug fixes
  - `refactor:` for code refactoring
  - `docs:` for documentation updates
  - `tests:` for tests addition and modification
  - `chore:` for maintenance tasks and environment setup

## Pre-Commit Verification Rules

Before committing code, submitting changes, or marking a task complete:

1. Run Ruff linter and formatter: `python -m ruff check --fix .` and `python -m ruff format .`.
2. Run static type analysis: `mypy cmd internal test`.
3. Run test suites: `pytest test/unit test/integration`.
4. Verify [`.ai/doc-api.md`](file:///c:/Users/ANIK/Desktop/Gemejime/Document%20AI%20Parsers/.ai/doc-api.md) is updated with all API, schema, or storage modifications.
5. Update [`.ai/progress-tracker.md`](file:///c:/Users/ANIK/Desktop/Gemejime/Document%20AI%20Parsers/.ai/progress-tracker.md).
